## Week 2 - Bits and Bytes
- Bits, Bytes, and Memory: A bit is the smallest unit of data, representing 0 or 1. Eight bits make one byte. Computers use volatile memory (RAM) for temporary data and non-volatile storage (HDDs and SSDs) to save data permanently.-
-  Representing Numbers and Text: Computers use binary (base 2) to represent numbers. Other number systems include decimal (base 10), octal (base 8), and hexadecimal (base 16). Text is represented using character encoding systems such as ASCII and Unicode, which assign numerical values to characters.
- Files and Data Storage: A file is a sequence of bytes stored on a storage device. Text files contain bytes intended to represent readable characters, while binary files store data such as images, audio, and programs. The software interpreting the bytes determines how the data is displayed or used.
